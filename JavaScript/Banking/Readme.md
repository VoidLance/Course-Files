### Banking Application Example in JavaScript
This javascript app was created for an activity in the software development course I'm on.

#### Where to find the hosted version
Since part of the instructions for the activity was to host it on a web server, I have uploaded it to the Software section of my personal website. It can be accessed at: [https://alistairsweeting.online/Software/Banking/html/] and only via direct link for the moment. I am unsure whether I want to add a navbar link at this time.

#### Difficulties I experienced
- I had forgotten I could use an array to create a set of accounts using the class, so creating and using accounts posed a bit of a challenge
- I wasn't sure how to implement the dropdown list I was thinking of for selecting an account. After a bit of searching through documentation, I decided that select would be the best option
- I also had difficulty implementing the function for selecting an account into the dropdown. After more searching through documentation, I settled on an event listener on the dropdown which uses the find function to select an account with a matching account holder and number (the dropdown options track number using value and account holder using text content)


However, I also did not even check the example on github that was linked on the course. Doing so would most likely have made solutions to many of the problems I faced more obvious.
