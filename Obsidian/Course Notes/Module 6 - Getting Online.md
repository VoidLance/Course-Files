<u>Getting Online</u>
- The first thing you need is a domain name.
- keywords in domain name impact SEO
- it is possible to get shared hosting, which comes with its own advantages and disadvantages. For example, if you are sharing your host server with a website that is breaking laws, your own site may get caught up in sanctions made against that site, due to sharing the same ip address
- FTP may be used to mirror files from your computer to the host server (File Transfer Protocol)
- For example Filezilla is a popular choice
- The server is set up so that there is a root directory. The website structure needs to be placed here
- sometimes servers are set up to look for home.html, but usually you will need to rename it to index.html
- the root directory is usually named appropriately and with a common scheme
- If a website has a lot of files, you can often compress it locally and unzip it once it is uploaded
- The next step is to configure DNS. This means setting up the host server to point to your domain name. This is done differently on each host. It may need to be done manually. In this case, you need to change the host DNS settings to point to the correct name server, as well as possibly to point the domain name server to the correct ip address
- When using php, most good hosting companies provide you with a database, which you will need to set up and connect it - before using php to modify it. It is important to first test that the database is connected and working correctly.
- You should then test all links, and may need to repair them.
- Your CPanel should have myphpadmin and other tools to manage different services like emails.
- you may also be able to install tools and services, including CMS (Content Management Systems) like Wordpress.
- The CPanel may also be have reporting tools and analytics, as well as security information
- You should then think about marketing the website. The first step to this is SEO. SEO is split into onsite SEO (all the semantic html elements, meta tags and website quality adjustments) and offsite SEO (content marketing, link building, social media marketing, blogging, content creation and relevant content)
- You may also want to market the website in ways other than SEO. This can include digital marketing such as emails, google pay-per-click, etc.
- you also need to think about the maintenance and upkeep of the website. It is a good idea to keep a backup of the website (note to self, I should add my website folder to github)
- often as a website developer, you may need to hand over control of the website to an administrator.
